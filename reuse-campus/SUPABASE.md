# Supabase deployment guide

The original backend is **PHP 8 + MySQL** (XAMPP). Supabase is **PostgreSQL** and does **not** execute PHP, so the deployment has two parts:

1. **Database** → Supabase PostgreSQL (migration + seed are already prepared here).
2. **PHP app** → any PHP host (the app connects to Supabase over `DATABASE_URL`).

> ⚠️ A hosted Supabase project can only be created/connected with **your own Supabase account**. I prepared everything locally with the Supabase CLI, but the final `login → link → db push` steps must be run by you (or with a token you provide).

---

## What was generated

```
supabase/
  config.toml                              # created by `supabase init`
  migrations/
    20261123000000_initial_schema.sql      # MySQL schema ported to Postgres
  seed.sql                                 # all demo data (same credentials)
config/database.php                        # now supports DB_DRIVER=pgsql + DATABASE_URL
.env.example                               # connection variable templates
```

### MySQL → Postgres changes made
| MySQL | Postgres |
|---|---|
| `ENUM(...)` | `VARCHAR + CHECK` |
| `AUTO_INCREMENT` | `GENERATED BY DEFAULT AS IDENTITY` |
| `ON UPDATE CURRENT_TIMESTAMP` | `set_updated_at()` trigger |
| `FULLTEXT KEY` | `GIN` index on `to_tsvector(...)` |
| `DATE_FORMAT()` / `DATE_SUB()` in PHP | auto-translated by `normalizeSql()` in `config/database.php` |
| Double-quoted SQL string literals | auto-translated to single quotes by `normalizeSql()` |
| `TINYINT(1)` | `INTEGER CHECK (col IN (0,1))` |

RLS is intentionally left off: the PHP app uses its own session auth and connects with the Postgres connection string (service-role equivalent). If you enable RLS, add policies for `service_role`/`postgres`.

## Step 2 — Create the hosted project (you must be logged in)

```bash
cd reuse-campus
supabase login
# Opens a browser to authenticate with your Supabase account.
```
In the Supabase dashboard: **New project** → choose name, DB password and region.
Copy the **Project Ref** from Project Settings → General.

---

## Step 3 — Link the local folder and push the schema

```bash
supabase link --project-ref YOUR_PROJECT_REF
# Enter the database password when prompted.

supabase db push          # applies supabase/migrations/*.sql
supabase db seed          # loads supabase/seed.sql (demo data)
```

Alternative: paste `supabase/migrations/20261123000000_initial_schema.sql` and
`supabase/seed.sql` into **SQL Editor** and run them in that order.

Verify in the dashboard's Table Editor: `users`, `listings`, `item_requests`, etc. should exist with demo rows.

---

## Step 4 — Get the connection string

Supabase dashboard → **Project Settings → Database → Connection string → URI**.
Use the **Session pooler** (port 6543) or direct (port 5432). Replace `[YOUR-PASSWORD]`.

```
postgresql://postgres.[PROJECT-REF]:[YOUR-PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres
```

---

## Step 5 — Point the PHP backend at Supabase

On your PHP host, set environment variables (do **not** commit real secrets):

```
DB_DRIVER=pgsql
DATABASE_URL=postgresql://postgres.[PROJECT-REF]:[YOUR-PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres
```

If your host doesn't inject env vars into PHP's `getenv()`, set them in `config/database.php`
or add a small loader in `config/config.php` that reads a local `.env`.

Also make sure the PHP extension **`pdo_pgsql`** is enabled on the host.

---

## Step 6 — Host the PHP app

Supabase does not run PHP. Deploy the `reuse-campus/` folder to any PHP 8+ host, e.g.:
- Shared hosting / cPanel with PHP 8+
- Render, Railway, Fly.io, or a VPS with Apache/Nginx + PHP-FPM
- Keep `assets/uploads/` writable (image uploads)

Demo credentials are unchanged: password `password` for students and admin.

---

## Local development without Docker (optional)

`supabase start` needs Docker Desktop. If you install Docker, you can run the whole
stack locally:

```bash
supabase start          # starts local Postgres + API at 127.0.0.1:54322
supabase db reset       # re-applies migrations + seed
```

Then set `DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:54322/postgres`.
